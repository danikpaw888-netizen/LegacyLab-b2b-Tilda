# Проверка в браузере

02.11.2026. Локальный прототип открыт в ChatGPT in-app browser после включения доступа. Проверены главная, каталог и R-450. На момент этого локального прохода сайт на Tilda ещё не публиковался. Последующая публикация и проверка описаны в `08-tilda-publication.md`.

## Отображение

Для каждой страницы установлены пять размеров viewport. Высота окна — 900 px. В этом браузере полоса вертикальной прокрутки занимает 15 px, поэтому доступная ширина документа меньше заданного viewport.

| Viewport | Ширина документа | Главная scrollWidth | Каталог scrollWidth | R-450 scrollWidth | Колонок в каталоге |
|---|---:|---:|---:|---:|---:|
| 1440 | 1425 | 1425 | 1425 | 1425 | 3 |
| 1024 | 1009 | 1009 | 1009 | 1009 | 3 |
| 768 | 753 | 753 | 753 | 753 | 2 |
| 390 | 375 | 375 | 375 | 375 | 1 |
| 360 | 345 | 345 | 345 | 345 | 1 |

Во всех 15 сочетаниях горизонтального переполнения нет. Заголовки и основные действия помещаются. На телефоне назначение, параметры и CTA R-450 находятся перед галереей. Таблица сохраняет две колонки и шрифт 14 px; значения переносятся. Изображения главной дополнительно проверены после прокрутки: они загружены, включая интерьер и схему склада. Предметная визуализация сохраняет пропорции.

Исходные измерения: [browser-results.json](browser-results.json). Снимки находятся в [screenshots](screenshots/); файлы с названием страницы и шириной — полные страницы. В полноформатных снимках закреплённая шапка может отображаться в позиции захвата: это особенность снимка длинной страницы. Для оценки первого экрана используйте [desktop-превью](screenshots/home-desktop-preview.png).

## Сценарии

| Проверка | Результат |
|---|---|
| Поиск R-450 | Одна видимая карточка |
| Радиосвязь → IP67 | Одна видимая карточка R-450; параметров разрешения камеры нет |
| Удаление чипа IP67 | Восстановлены три радиостанции |
| Переключение на видео | Показаны разрешение и установка; параметры радиосвязи исчезли |
| Несуществующая модель | Ноль результатов, понятный текст и два действия |
| Сброс кнопкой и Enter | Возвращены 12 товаров, очищен поиск и параметры URL |
| Сортировка Я–А | Реальный порядок изменился: R-520 … A-210 |
| Мобильные фильтры | Раскрываются в потоке, горизонтального переполнения нет |
| Мобильное меню | Закрывается после перехода к разделу |
| Решение для склада | Тип объекта передан в форму |
| Запрос с карточки | Модель R-450 и страница переданы автоматически |
| Пустая форма | Ошибки у имени и контакта; фокус на имени |
| Неверный контакт | Подсказка о формате; фокус на контакте |
| Email и телефон | Принимаются; результат честно сообщает «Запрос не отправлен» |
| Клавиатура в dialog | Tab/Shift+Tab замыкают последовательность внутри окна |
| Escape | Закрывает окно, фокус возвращается на исходную кнопку |
| Галерея R-450 | Размерная схема и схема органов управления открываются; alt обновляется |
| FAQ | Ответ раскрывается по нажатию |

При проверке найден выход фокуса за границы native dialog. Добавлен явный цикл Tab/Shift+Tab; повторная проверка обоих направлений прошла. Исправление перенесено в офлайн-версию и вставки Tilda. У дополнительных карточек уточнены заголовки назначения по категории.

На проверенных локальных страницах в журнале браузера ошибок JavaScript не обнаружено. После исправлений повторно прошли 53 автоматические проверки, проверки 16 офлайн-страниц и самодостаточной вставки каталога.

## Границы проверки

Это проверка локального прототипа в одном браузере. Она не заменяет проверку после сборки в Tilda. Скринридер, 200% масштаб и устройства с другими браузерами отдельно не тестировались. Уменьшение движения предусмотрено в CSS, системная настройка в этом проходе не переключалась. Рассчитаны основные контрастные пары; полный аудит соответствия WCAG не заявляется. Приём заявок остаётся тестовым, получатель не подключён.

После переноса на Tilda выполнен отдельный интеграционный проход по 15 страницам и 15 сочетаниям основных страниц/ширин. Исправлено переполнение заголовка кейса на 360 px: ограничена ширина и уточнён текст «Один объект. Единая система.». Итоговые измерения опубликованной версии — в `tilda-published-results.json`.
